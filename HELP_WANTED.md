# Help wanted

SEC Experiment is open to contributions. Below is the hardening work that would make it stronger, roughly in order of impact. Pick anything, comment on (or open) an issue so others know you are on it, and see [CONTRIBUTING.md](CONTRIBUTING.md) to get started.

Found a vulnerability instead? Please report it privately, see [SECURITY.md](SECURITY.md).


### Replication

**Medium.** Rerun the experiments on a different video set and report whether the conclusions hold.

### Fixed random seeds

**Good first issue.** Make every experiment take an explicit seed so results are reproducible run to run.
